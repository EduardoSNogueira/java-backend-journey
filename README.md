# Java Backend Journey

Repositório de estudos de Java de Eduardo Nogueira, estudante de Engenharia de Software no IESB. Reúne exercícios do curso do Nélio Alves na Udemy e aplicações práticas de estudo.

## Organização

| Pasta | Conteúdo |
|---|---|
| [01-java-fundamentals](01-java-fundamentals/) | Entrada e saída, cálculos, condicionais e repetição |
| [02-java-oop](02-java-oop/) | Classes, objetos e exercícios de orientação a objetos |
| [WiseCash](02-java-oop/05-financial-control/) | Aplicação financeira no terminal; projeto pausado |

## Situação atual

Retomada dos estudos em outubro de 2026, com revisão prática de sintaxe e continuidade da seção 9 do curso: construtores, this, sobrecarga e encapsulamento.

Os exercícios registram etapas de aprendizagem. A existência de uma tecnologia no repositório não significa domínio completo dela.

## Próximos passos

- Consolidar métodos, objetos, construtores e encapsulamento.
- Estudar arrays, listas, exceções e demais fundamentos de orientação a objetos.
- Construir um pequeno controle de estoque no terminal.
- Evoluir para persistência relacional, APIs REST com Spring Boot e testes.

## Como explorar

Cada exercício ou projeto está em uma subpasta própria. Abra a pasta correspondente na IDE e consulte seu README, quando disponível. Os requisitos e a configuração de execução devem ser verificados no pom.xml de cada projeto; não há uma execução única para todo o repositório.
